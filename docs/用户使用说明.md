# 学生选课系统使用说明

新版增加“成绩中心”“个人资料”“公告通知”，管理员另有“公告管理”。

- 教师在成绩中心选择学期和教学班，输入分项成绩，点击“保存全班草稿”，全班完整后点击“发布全班成绩”。发布后修改须先撤回。管理员也可维护成绩。
- 学生在成绩中心查看已发布成绩及已获学分，未发布成绩不会显示。已录入成绩的课程不能自行退课。
- 个人资料可修改邮箱、联系电话、简介；学号、姓名、专业等由管理员维护。
- 点击公告查看正文，再点“确认已读”。管理员可按角色发布、置顶、设置展示时间，已发布公告可撤回。
- 管理列表、选课记录、成绩和学生名单页面提供 CSV 导出，使用 Excel 打开即可。导出遵守角色权限和当前筛选。

具体规则与演示账号见 [功能完善说明](功能完善说明.md)。

## 登录

双击项目根目录的“启动选课系统.cmd”，访问 http://127.0.0.1:8081。初始账号与密码保存在 release/windows/账号信息.txt。管理员账号为 admin，学生用学号登录，教师用工号登录。

本机部署启用免密入口后，点击登录页的「选择用户免密登录」。选择学生、教师或管理员，再点击列表中的账号即可登录。进入系统后，用右上角的「切换身份」更换账号。列表支持按姓名、学号、工号或账号搜索。

通过“账号设置”可修改本人密码。密码至少 10 个字符，包含字母和数字，UTF-8 长度不超过 72 字节；修改后需要重新登录。账号停用或被重置密码后，已有登录会失效。

## 管理员操作顺序

1. 在“教师管理”和“学生管理”中新建档案，指定初始密码及启用状态。学号、工号建立后不可改，其他档案信息可编辑。
2. 在“课程管理”中新建课程，设置编号、名称、学分、学时及简介。
3. 在“学期设置”中配置学期日期、选退课开始与结束时间、每位学生的学分上限。
4. 在“开课管理”中新建教学班，选择课程、学期、已启用教师和人数上限。
5. 添加一个或多个上课时间段，包含星期、起止节次、起止周次和教室。草稿可暂不排课，发布前必须排课。
6. 发布教学班后，学生即可在该学期课程目录中看到它。发布时自动检查教师与教室冲突。
7. 使用“名单”查看当前有效选课学生，或在“选课记录”中按学生、课程、学期和状态查询历史。

### 修改和删除规则

- 人员通过停用保留档案，不物理删除账号历史。
- 被开课引用的课程不能删除，且仅能改名称和简介。
- 有教学班的学期不能删除，学分上限不能低于已有学生的有效选课学分。
- 有选退课历史的教学班只能调整容量与状态，不能改课程、教师、学期和上课安排。
- 容量不能低于当前有效人数；有有效选课时不能改回草稿。
- “关闭”停止新增选课；学生仍可在允许的选退课时间内退课。

## 学生选课

1. 打开“课程目录”，按学期和关键词查找课程。
2. 核对学分、教师、上课安排与人数，点击“选择课程”并确认。
3. 在“我的选课”查看已选学分和记录；在“我的课表”按学期和周次核对安排。
4. 允许时间内点击“退选课程”。退课释放名额，记录保留为“已退”；之后可再次选课。

同时选择多门课程时，勾选课程目录中的「待选」。如有冲突，批量选课区域会显示涉及的课程和重叠时间。移除冲突课程或改选其他教学班后，点击「确认选课」统一提交。每次最多选 20 个教学班，全部通过校验后一起生效。

系统会阻止：超出选课时间、教学班满员、同学期重复课程、学分超限和课表冲突。时间冲突同时比较星期、上课周次与节次。人数和规则以提交时服务器检查结果为准。

窄屏下可左右滚动表格和课表。课表只显示当前选定周次实际安排的课程。

## 教师使用

通过“我的教学班”查看本人授课课程、上课安排、状态和人数；通过“学生名单”切换本人教学班，查看当前有效选课学生。学生退课后会从有效名单中移除。教师无法读取其他教师的名单。

## 常见情况

- 看不到课程：确认选对学期，管理员已经发布教学班且教师账号启用。
- 课程按钮不可选：可能已选、满员或不在选课时间；点击刷新获取最新人数。
- 修改排课被拒绝：已有选退课历史时排课被冻结，需按教学安排另开新班。
- 账号突然退出：可能超时、被停用、密码被重置或系统刚完成更新。
- 课表为空：确认学期、周次，以及课程当前是否为有效选课。
