# 成绩、资料、公告与数据导出

本次按用户指定的顺序完善四部分，沿用 Spring Boot、Vue 与 SQL Server。原账号、密码、课程和选课记录保留。

## 成绩中心

- 学生查看本人有效选课中已发布的成绩，可按学期筛选并导出。
- 教师仅能管理本人教学班，管理员可管理全部教学班。
- 平时和期末成绩为 0～100，可留空保存草稿，最多两位小数；平时权重为 0～100 的整数，全班统一。
- 总评按百分比计算，四舍五入到两位小数。全班成绩完整且已保存后才能发布。
- 发布后分数只读，须先撤回才能编辑。撤回后学生暂不可见，重新发布后恢复。
- 成绩版本号防止并发覆盖，名单变化后必须重新加载。保存、发布和撤回与选退课使用相同的学期、教学班锁顺序。
- 已录入任一成绩的学生不能自行退课；教师清空两项成绩并保存后可解除该限制。已发布成绩的教学班停止新增选课。
- 学生汇总已发布门数、待发布门数、学分加权均分、已获学分和演示绩点。60 分计及格。演示绩点低于 60 为 0，60 起为 1，每增加 10 分加 1，上限 4；这不是学校正式绩点规则。

## 个人资料

所有角色可修改本人邮箱、联系电话、个人简介。学号、工号、姓名、专业、班级、院系只读，由管理员维护；接口从 Session 确认身份，不接受客户端指定的用户编号或角色。

## 公告通知

管理员可创建草稿、编辑、发布、撤回、设置接收角色、置顶和展示时间。开始时间为空时发布后立即展示，截止时间为空时不限；过期、草稿和不面向本人角色的公告不会出现在阅读列表。

用户打开公告后主动确认已读。公告修改后版本递增，旧已读记录保留，更新内容重新显示未读。工作台展示最新三条有效公告和未读数量。正文按纯文本展示。

从未发布的草稿可删除；曾发布的公告通过撤回保留历史，不物理删除。

## CSV 导出

| 角色 | 导出范围 |
|---|---|
| 管理员 | 学生、教师、课程、学期、教学班、选课记录，以及所选教学班成绩 |
| 教师 | 本人教学班学生名单、成绩 |
| 学生 | 本人选课记录、已发布成绩 |

导出沿用页面筛选条件，最多一万条；超过需缩小范围。CSV 使用 UTF-8 BOM、CRLF 和双引号转义；危险公式前缀转为文本。不包含密码、密码散列或数据库凭据。

## 数据库升级

新增 `student_grade`、`user_profile`、`announcement`、`announcement_read` 四表。增量脚本为 `backend/src/main/resources/db/migrations/V002__learning_features.sql`，可重复执行，不清空原八表。

`deploy/windows/Upgrade-Deployment.ps1` 先备份 SQL Server 和旧程序，再构建、执行增量迁移、启动，最后校验原八张表的行数及数据指纹。异常时恢复旧程序，保留数据库。新增表不妨碍旧版本运行。
