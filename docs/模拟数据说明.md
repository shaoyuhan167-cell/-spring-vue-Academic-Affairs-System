上课安排包含理论和实验时间段，覆盖工作日、周末及不同周次。当前共有 17 个已发布班、1 个已关闭班、1 个草稿班。

## 写入与复用

脚本为 deploy/windows/Seed-DemoData.py，使用已有管理员登录，通过实际业务接口创建数据、选课和退课，未修改原有账号资料或密码。运行前已生成 SQL Server 原生备份。

本批数据完成标识保存在 .runtime/mock-data-manifest.json。重复执行脚本会仅查询数量，不重复新增，也不覆盖后续人工修改。

~~~powershell
python -X utf8 .\deploy\windows\Seed-DemoData.py
~~~

只读检查可附加 --check。数量摘要保存在 .runtime/mock-data-summary.json。若之后修改管理员密码，需要同步脚本的管理员登录方式；请勿通过删除完成标识来强行覆盖已有数据。
