# 学生选课系统架构

## 当前实现

系统已实现管理员的学生与教师档案、课程、学期、教学班排课与发布管理，学生选退课与个人课表，教师授课安排与学生名单，以及密码修改、角色权限和登录失效控制。

~~~mermaid
flowchart TD
    Browser[学生 / 教师 / 管理员] --> Vue[Vue 页面与角色导航]
    Vue -->|同源 JSON 与 Session| Security[Spring Security / CSRF / 账号状态校验]
    Security --> Controllers[认证、管理、选课、授课 Controller]
    Controllers --> Services[事务服务与业务规则]
    Services --> Mapper[MyBatis Mapper 与数据库方言]
    Mapper --> DB[(SQL Server)]
~~~

笔记本运行时，Vue 构建产物装入 Spring Boot JAR，统一从 http://127.0.0.1:8081 提供页面与接口。SQL Server 保存业务数据。H2 仅用于 Maven 隔离测试。

## 前端职责

- ResourceManagementView：学生、教师、基础课程与学期的查询和编辑。
- ClassManagementView：开课、排课、发布、关闭与名单查询。
- CourseListView：课程目录和选课。
- EnrollmentView：学生本人记录或管理员全局查询。
- TimetableView：按学期与周次显示个人课表。
- TeachingView：本人教学班和名单。
- AccountView：修改本人密码。
- DashboardView：按角色显示实际数量和使用指引。

## 认证和权限

密码使用 BCrypt。登录后轮换 Session 编号，浏览器通过 HttpOnly Cookie 维持会话，写请求保留 CSRF 校验。URL 层限制管理员、学生和教师入口，Controller 方法权限再次限定角色，服务层验证选课记录和教学班的本人归属。

Session 保存凭据版本指纹。停用账号、重置密码或本人改密后，后续私有请求对照数据库使旧 Session 失效。前端导航不是权限依据。

## 选退课事务

1. 按编号锁定学期，协调选退课与规则、教学班变更。
2. 锁学生，防止同时选择不同班绕过冲突和学分校验。
3. 锁目标教学班，重新读取状态、容量和有效人数。
4. 验证选课窗口、重复课程、学分与排课交集。
5. 插入或复用记录；退课仅改状态和时间。

SQL Server 使用 UPDLOCK、ROWLOCK。H2 隔离测试使用 FOR UPDATE。MyBatis 使用语句级本地缓存，防止加锁后读到事务内旧查询。所有锁和写操作处于同一事务。

当前按学期串行协调这些写操作，适用于实习规模。已验证并发争抢与同学生冲突的正确性，尚未进行大规模容量评估。
