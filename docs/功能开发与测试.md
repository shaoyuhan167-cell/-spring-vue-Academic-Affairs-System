# 核心业务开发与测试记录

日期：2026 年 11 月 10 日。

## 本轮实现

| 角色 | 已实现功能 |
|---|---|
| 管理员 | 学生/教师新增编辑、分页搜索、启停、密码重置；课程与学期维护；教学班排课、发布、关闭、名单和选课历史查询 |
| 学生 | 课程搜索与按学期筛选、选课、退课、历史记录、已选学分和个人周课表 |
| 教师 | 本人教学班、选课人数、上课安排及有效学生名单 |
| 全部角色 | 登录退出、密码修改、旧登录失效、角色导航和服务端权限 |

保留原有 SQL Server 表结构和已部署数据。写接口在后端验证规则，客户端按钮状态只用于提示。

## 自动化测试

- H2：8 项框架测试和 11 项业务测试，共 19 项。
- SQL Server：同一组 11 项业务测试在专用验证库运行。
- 更新部署后：34 项只读 HTTP 检查通过，八张业务表的数据校验一致。
- 框架用例：匿名访问、CSRF、错误密码、角色登录、Session 轮换、权限、参数校验和退出。
- 业务用例：档案分页和引用保护、通配符搜索、选退课与复选、课表与名单、时间窗口、争抢最后名额、同学生并发冲突、重复课程、学分上限、教师与教室冲突、历史排课冻结、归属权限、停用和改密使旧登录失效。

SQL Server 测试报告保存到 .runtime/sqlserver-business-tests.xml；测试脚本见 deploy/windows/Run-SqlServerTests.ps1。

## 浏览器验收

在 8082 端口的独立验证实例中实际完成：

1. 新增学生并使用该账号登录。
2. 新增和编辑基础课程。
3. 选择课程与教师，添加时间段并发布教学班。
4. 学生选择刚发布的教学班，在记录中看到有效选课与学分。
5. 周课表正确显示课程、教室、教师和节次跨度。
6. 任课教师在名单中看到该学生。
7. 学生退课后学分归零，退课时间与历史仍保留。
8. 验证快速关闭后重新编辑的弹窗修复，以及学期日期时间字段回显。
